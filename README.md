# Web Scraper using Python

This script extracts data from a website using Python.

## Features:
- Fetch website data
- Extract page title
- Easy to use

## How to run:
1. Install requirements:
   pip install requests beautifulsoup4
2. Run script:
   python web_scraper.py

- Data collection
- Automation
